# PSD Folder States for Krita

Python-плагин для Krita, который автоматически восстанавливает свёрнутое или развёрнутое состояние папок (групп слоёв) при открытии файлов формата `.psd`.

## В чём проблема?
По умолчанию при импорте `.psd` файлов в Krita вся иерархия слоёв принудительно раскрывается. Если вы работаете с многослойными иллюстрациями или страницами комиксов, где папки вложены друг в друга, ручное сворачивание десятков групп становится рутинной задачей. Этот плагин решает проблему раз и навсегда в фоновом режиме.

## Особенности
- **Автоматизация:** срабатывает сразу при открытии `.psd` файла в Krita.
- **Поддержка кириллицы:** корректно читает русские названия слоёв и папок из метаданных `luni`.
- **Без сторонних зависимостей:** написан на чистом Python с использованием встроенных модулей и Krita API.

## Установка

### Способ 1 (Рекомендуемый)
1. Скачайте готовый архив `psd_folder_states.zip` из раздела **[Releases](../../releases)**.
2. Откройте Krita и перейдите в меню: **Сервис → Сценарии → Импортировать плагин Python...**
3. Выберите скачанный `.zip`-архив.
4. Перейдите в **Настройка → Настроить Krita → Управление плагинами Python**, поставьте галочку рядом с **PSD Folder States** и **перезапустите Krita**.

### Способ 2 (Ручная)
Скопируйте папку `psd_folder_states` и файл `psd_folder_states.desktop` в директорию `pykrita` ваших ресурсов Krita (её можно открыть через *Настройка → Управление ресурсами → Открыть папку ресурсов*). Затем перейдите в **Настройка → Настроить Krita → Управление плагинами Python**, поставьте галочку рядом с **PSD Folder States** и **перезапустите Krita**.
